HyperCPU Project

Welcome!

The HyperCPU Project is an open source project dedicated to development of an experimental instruction set architecture (ISA) and a various software working with it.

The project was started in March 2024. A year later, in April 2025, a little development team was formed, and a Telegram chat and web site were developed and launched in short time.

The project is developed just for fun, but we hope that our work will be interesting and useful for others.

Our repositories

HyperCPU The HyperCPU ISA itself.
hcc The C compiler developed to help you write C programs for HyperCPU.
